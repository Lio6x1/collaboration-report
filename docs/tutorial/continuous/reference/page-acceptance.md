# 自己的学习实例：页面验收

先完成[06](../06-integration.md)的完整READY与真实模块关口。浏览器只打开自己start输出的HTTPS地址。用两个专门的学习账号A/B和新建测试文档操作；开发SMTP验证码只在自己的本地夹具中收取，不代表已发到真实邮箱。每行记录实际观察和失败码，尚未操作的行保持未验收。

| 项目 | 实际操作与应观察的结果 | 当前讲义与失败定位 |
| --- | --- | --- |
| 注册与验证码 | 两次新密码不一致时页面阻止提交；弱密码后端拒绝。发送中/冷却内按钮禁用，另一标签也受后端冷却约束。最近挑战完成注册，已绑定邮箱不能新增第二个账号。 | [A01](../lessons/account/01-authentication.md)：分别看验证码无效、冷却、依赖故障、邮箱占用。找回未注册邮箱统一提示不证明投递。 |
| 多账号与昵称 | 同浏览器两个标签主动登录A/B，刷新后各自昵称和内容保持；退出A不让B串号。编号至少八位展示，输入归一到真实ID。 | [A01](../lessons/account/01-authentication.md)、[A08](../lessons/account/08-output-and-wiring.md)：Cookie槽位只选凭据，不能产生身份或免CSRF。重名用编号区分。 |
| 组织与知识库 | 复制组织八位编号，B从“创建或加入组织 → 申请加入”提交说明，等待审批。点击选择成员后弹出可搜索名单，后页自动查找，选择后收起；给有效成员设置库角色和创建资格；授予/撤销按当前状态互斥，更新中不重复点。刷新、后退和后页库返回有效。 | [A03](../lessons/account/03-organizations.md)、[D02](../lessons/document/02-workspace-content.md)：普通成员不能因看见卡片取得管理权。 |
| 空间导航 | 先选个人/组织空间，再选组织名，核目录、当前位置及创建目标一致。后页组织可加载；无组织或撤权不显示旧目录。切换后立即刷新及加载完后刷新，都恢复合法选择。 | [D02](../lessons/document/02-workspace-content.md)：查空间/库资格、游标及真实路由。桌面侧栏与390px窄屏入口均检查。 |
| 文档设置与入口 | 文档信息在目录管理之前；目录按章列出，在右侧⋯中新增、改名、移动或生成拆合/删除预览；从当前库创建文档。阅读和编辑分开，进入MAIN/BRANCH在当前标签，刷新后重核资格并恢复合法工作区。 | [D02](../lessons/document/02-workspace-content.md)、[C02](../lessons/collaboration/02-admission-save.md)：URL不是票据，旧单元/epoch不能继续写。 |
| 个人协作管理 | 邀请按有效/失效/全部筛选，申请按待处理/已处理切换，每页20条、最新在前。删除失效邀请或已处理申请需确认；不撤销已获权限，本人申请历史保留。断网时在原弹窗确认操作结果，不能重新提交新号。 | [D01](../lessons/document/01-identity-access.md)：检查状态、原修订、管理资格和原操作恢复。 |
| 可靠保存与合入 | A改MAIN并确认保存；B共同支线保留自己的新增段落，兼容时合入MAIN。旧代次本机输入先恢复，保存返回后能读到可靠内容。 | [D03](../lessons/document/03-main-draft.md)、[C04](../lessons/collaboration/04-fixed-workflows.md)：查真实FLUSH及固定输入，不能以清空支线解决冲突。 |
| 阅读更新 | B无选区/草稿时，A保存后B在下一次成功摘要检查更新。B正在评论/设置/编辑则保留输入并提示变化；截图快捷键不整页重载。 | [D02](../lessons/document/02-workspace-content.md)：503/断网不是失权，阅读更新也不是编辑保存确认。 |
| 格式、代码与图片 | 设置宋体/仿宋、小四、对齐/缩进，分别插入短代码与长代码块。粘贴PNG，等上传与正文保存，重开可读图；等比缩放不再次上传。 | [F01](../lessons/foundation/01-fixed-content.md)、[D08](../lessons/document/08-resources-storage.md)：0字节预留不等于没有余额，检查真实资源引用/配额。 |
| 拆分与父章 | 第一章放章前段落、表格、两个真正H2；第二章放另一段。预览后确认，章前内容和小节仍归第一章，写作入口有名。有人在线时完成保存握手，失败保留输入。 | [D04](../lessons/document/04-structure.md)、[C05](../lessons/collaboration/05-structure-online.md)：预览后新保存可要求重新预览；核父子身份而非数组顺序。 |
| 弹窗和任务 | 新建/加入弹窗关闭重开保留输入；未知操作先查原结果。浮层互斥、Escape返回按钮，切换页面不取消上传。审核冲突返回列表再进入保留人工候选，明确关闭才清除。 | [D06](../lessons/document/06-merge-conflict.md)、[D08](../lessons/document/08-resources-storage.md)：界面忙碌状态不能替代原号恢复。 |
| 评论定位 | 选区发评论，标记/卡片对应；主评论可见、回复按需展开，原文折叠限高。保存无关段落后可靠映射仍定位；引用改变时保留历史引用。 | [D09](../lessons/document/09-comments-notifications.md)：稳定块/原偏移/quote不匹配时不伪造当前高亮；核草稿保留。 |
| 固定审核 | 较长支线送审，列表摘要、详情展开；按原base显示增删/格式差异。A有MANAGE可自审，普通REVIEW不能审批自己曾提交的请求。送审后再改草稿，原轮次保持。 | [D05](../lessons/document/05-submission-review.md)、[D06](../lessons/document/06-merge-conflict.md)：冲突/修改要求会阻止合并，反向更改也要新审核。 |
| 正式搜索 | 发布唯一词再搜索，等待真实投影；同一文档多命中仍一条，同标题两文档保留两条。撤下/撤权后不输出失效正式内容。 | [D07](../lessons/document/07-publication.md)、[S01](../lessons/search/01-event-authority.md)、[S03](../lessons/search/03-candidates-cursor.md)：MAIN草稿不能当正式搜索结果。 |
| 导出 | 阅读页创建Word/PDF/Markdown，等原任务完成再下载，检查图片/表格/长代码。多个任务按worker上限运行，Windows不弹控制台。 | [D10](../lessons/document/10-exports.md)：核固定manifest、预算、实际转换器和当前下载资格；未知原号不换新manifest重发。 |
| 回收和恢复 | 用一次性文档，经“更多操作 → 移入回收站”核名；取消无写入，确认才移动。恢复后仍私有未发布，旧票据拒绝。 | [D12](../lessons/document/12-trash-transfer.md)：原号恢复、当前管理资格、配额/引用及隐藏搜索水位。 |
| 转移、关闭与注销 | 另建一次性账号/组织/文档，转移在真实接受前保留原归属。组织“更多操作 → 关闭组织…”需输入当前名称，取消重开清空名称。未知保持原操作，刷新或列表空后仍能查进度。注销核私有清理和公开固定版本留存。 | [A06](../lessons/account/06-account-close-preparation.md)、[A07](../lessons/account/07-closure-recovery.md)、[D13](../lessons/document/13-account-retirement.md)：HANDOFF_REQUIRED先交接，不能把租约过期当完成。 |
| 重启和备份 | 06正常停止/重启后账号、可靠正文、图片保留；核同owner/卷。完成本机后再备份隔离恢复。 | [当前备份步骤](backup-and-restore.md)：先保存自己的源码提交，不删除卷掩盖错误。 |

页面还是旧版本时先在自己的工程构建web，确认URL属于同一次start输出，再重新加载。预览总变化时先确认H2、可靠保存与持续编辑者；导出排队时核原任务和有限预算，重复点击不能解除故障。记录中只保留稳定错误码，不粘贴Cookie、验证码、配置或密钥。


## 长列表翻页验收

先准备超过一页的隔离测试记录，再检查“上一页 · 第N页 · 下一页”。只有一页时分页栏隐藏；翻页替换当前列表，返回上一页重新向服务端核验，不把已看过的数据当作仍有权限。游标不是总页数，空页带下一页入口时仍可继续。

| 列表 | 每页条数 | 额外核对 |
| --- | --- | --- |
| 通知 | 10 | 标读后刷新当前页，不能把本页未读数当成全部未读数；换账号清旧结果。 |
| 主评论 | 10 | 服务端先按正文版本和MAIN/BRANCH/REVIEW上下文筛选；回复选中后每批20条按需读取；翻页保留选中讨论与草稿。 |
| 知识库卡片 | 12 | 名称搜索能找到后页对象；搜索或换空间回到首页。 |
| 成员、文档、邀请、申请、转让、回收站 | 20 | 当前成员在后页或搜索之外仍按详情返回的本人关系判断管理入口；筛选变更回到首页，撤权清旧结果。 |
| 审核请求、轮次、修改要求、正式版历史 | 20 | 已选审核详情、固定轮次、意见草稿、固定发布预览和原确认修订不随列表翻页改变。未加载的修改要求不能被当作不存在。 |

游标过期时使用该列表的刷新入口回到首页，不反复提交旧游标。审核默认选择可继续扫描有界元数据来定位后页的当前请求；不能用首页末条历史冒充当前工作。耗尽定位预算时明确手选，不偷偷打开任意旧正文。章节目录与成员选择弹窗沿原目录导航、搜索和按需读取，不套用上述管理列表分页栏。

当前文档卡片是链接。正文页先点“编辑文档”，再选“编辑主线/编辑共同支线”；编辑后用“保存并返回文档”进入“版本与发布”，或送审完成后点“保存并查看审核记录”。审核与发布操作在对应页签完成。浏览器回归必须沿当前入口走完整流程，不能使用旧的同屏编辑/审核布局。
