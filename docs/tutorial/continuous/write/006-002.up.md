## 为什么创建这个文件

给任务与来源恢复就绪检查添加覆盖索引。

就绪探测每秒执行时不能加载大payload的聚簇页；新增索引改善访问路径而不改变业务事实。

写之前先按这条执行路线理解各段的连接：

1. 四库durable_task加task_pending(state,kind)。
2. Document加task_kind_due便于按种类选到期候选；三库gate_recovery与auth_recovery覆盖关闭证明联查。

本文件需要守住的边界：

- 索引只加速候选筛选，任务领取仍需主键当前读锁与原payload核验；不得以索引结果代替事务资格。
