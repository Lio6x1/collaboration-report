## 为什么创建这个文件

限定Edge代理接入，按连接顺序处理OPEN/UPDATE/FLUSH/SYNC和结构控制帧。

网络帧可并发到达而授权/保存是异步流程；必须有顺序链和有界输入预算。

写之前先按这条执行路线理解各段的连接：

1. upgrade核/collaboration、origin、Edge证书与x-edge-handler
2. maxPayload1500000，禁压缩；3秒内必须OPEN且pending最多32
3. chain串行解析JSON，首帧OPEN成功attach生命周期后才send READY
4. 后续委派对应引擎用例，结果仍经授权send输出
5. 权限错误结束连接；INVALID_CONTENT/DEPENDENCIES_MISSING保留稳定错误码

本文件需要守住的边界：

- 二进制帧和超队列预算直接终止
- OPEN依赖返回时socket可能CLOSING，不能补发READY或提前结算
- SAVED由持久用例产生，transport不能自行ACK收包

// 每连接32帧输入预算、三秒OPEN及原顺序链都在传输层；SAVED/FLUSH由实际用例给出。
export function attachWSS(cfg, http, engine) {
  const wss = new WebSocketServer({
    noServer: true,
    maxPayload: 1500000,
    perMessageDeflate: false,
  });
  http.on('upgrade', (req, socket, head) => {
    if (
      req.url !== '/collaboration' ||
      req.headers.origin !== cfg.origin ||
      !req.socket.authorized ||
      !req.socket
        .getPeerCertificate()
        .subjectaltname?.split(', ')
        .includes('URI:spiffe://collaboration-report/edge') ||
      !req.headers['x-edge-handler']
    ) {
      socket.destroy();
      return;
    }
    wss.handleUpgrade(req, socket, head, (ws) => {
      let b,
        chain = Promise.resolve(),
        pending = 0;
      const timer = setTimeout(() => ws.terminate(), 3000);
      timer.unref();
      ws.once('close', () => clearTimeout(timer));
      ws.on('error', () => ws.terminate());
      ws.on('message', (raw, binary) => {
        // 输入队列有界；串行处理同连接，不让OPEN/UPDATE/FLUSH互相越过。
        if (binary || ++pending > 32) {
          ws.terminate();
          return;
        }
        chain = chain
          .then(async () => {
            let input;
            try {
              input = JSON.parse(raw);
            } catch {
              throw new RPCFailure(3, 'MESSAGE_INVALID');
            }
            if (!b) {
              if (input.type !== 'OPEN') throw new RPCFailure(3, 'OPEN_REQUIRED');
