## 为什么创建这个文件

把导出预算硬上限扩展到最多8个worker对应2GiB。

可配置工作池需要总预算随并发变化，实际准入仍受单行锁和256MiB乘worker数限制。

写之前先按这条执行路线理解各段的连接：

1. ALTER export_budget删除008第二个CHECK，再添加reserved_bytes/used_bytes各不超过2147483648。

本文件需要守住的边界：

- 数据库硬上限不是默认可用额度；业务仍按实际workers核算，不得一律放行2GiB。
