## 为什么创建这个文件

为仅空的新安装库提供防误用回滚保护。

DROP DATABASE不可恢复，必须先证明四库所有业务表为空才允许执行清除。

写之前先按这条执行路线理解各段的连接：

1. assert_v001_empty逐表检查业务行，发现任何一行就SIGNAL拒绝。
2. 全部为空才CALL成功、移除过程并DROP四库。

本文件需要守住的边界：

- 不得在含用户数据或已追加迁移的实例运行；该脚本不是通用生产降级方案。
