# 07 学习记录、练习与独立答案

每阶段在自己的笔记记四件事：请求从哪个handler/RPC/WSS进入；哪个logic决定权限与状态；哪些SQL必须同一事务；哪项反例阻止什么错误。保留实际命令、输出及尚未执行项。文件核对只检查材料，不能替代这些记录。

先不看答案尝试：

1. 账号：给新密码表加“只有大小写字母”和“数字+特殊字符”例子，解释旧登录规则为什么不同；不能把故障统一改成账号密码错。
2. 目录：第一章前言放表格，再放两个真正H2，第二章保留独立段落；让支线落后主线并有自己的文字，解释在线拆分如何保留父章、表格与支线输入。
3. 审核：固定提交后继续改草稿，证明原轮次不变化；重试相同operation时为何不能生成第二轮？
4. 搜索：撤下正式版后为何不能只删除ES而不保留隐藏水位？哪条domain/index反例能证明？
5. 导出：两个用户连续提交多任务，解释HTTP登记、固定worker、外部进程、下载资格四者分别做什么；取消进程树怎样防子进程继续占输出。

五题的[独立答案与对应验证](reference/exercise-answers.md)均按本路线当前模型、固定版本和测试编写。可以先尝试，也可以直接读答案后推演；跳过练习不影响下一课的必需实现。先运行本路线对应规则和真实测试，再解释反例，不把答案粘过去当作练习完成。

改变业务规则时允许自己的代码与参考摘要不同，记录差异和新增验证理由。若只是为让测试变绿而删权限检查、忽略UNKNOWN、增加任意等待、返回假成功，就没有完成练习。未执行的云服务/服务器验收保持未执行。
