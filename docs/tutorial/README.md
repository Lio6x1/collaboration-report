# 协作报告：从空工程学习当前版本

从[Windows准备](continuous/00-start.md)开始，再按[39课目录](continuous/lessons/README.md)连续完成自己的同一个工程。后端与SQL亲写，前端、测试和生成契约从明确的支持包复用。

每课先解释要创建的文件与用途，再解释模型、字段和消费者接口，跟随具体业务实现SQL和异常处理，最后接入依赖、路由并检查预期。逐段操作页包含全部待输入代码；只在操作页输入一次，讲义中的同名代码用于讲解，完整答案用于写完后核对。

- [完整学习路线](continuous/README.md)：00准备，01～05编写，06自己的实例联调，07练习。
- [功能测试](functional-testing.md)：离线规则、真实接口与浏览器分别验收。
- [前端联调](frontend-integration.md)：同源、标签会话、CSRF、图片和WSS。
- [项目介绍](project-introduction.md)、[演示](demo.md)、[面试自测](interview.md)。
- [当前质量与教学审查](../delivery/CURRENT-REVIEW.md)。

保留一个当前全量版本。旧章节、历史Git复原及current增量不再作为材料分发。不要拿已完成产品代码覆盖自己的学习成果。Windows环境、命令解释、预期和排错在课程内；静态校验不能替代你自己的功能验收。
