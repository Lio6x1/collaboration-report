# 当前版本与验证范围

本页说明当前产品、课程入口及已验证范围。功能验收记录截至2026年10月13日；2026年11月25日进行公开仓库整理，只复核材料、源码同步与上传范围，不将历史验收写成本次新运行结果。

## 产品与架构

- 四个业务服务：Account、Document、Search使用Go，Collaboration使用Node.js；各自拥有私有数据库，经明确契约通信。
- 支持组织协作、多人富文本、章节级主线与共同支线、固定送审、审核合并、冲突处理、反向变更、发布搜索、资源、批注通知及DOCX/Markdown/PDF导出。
- 协作服务当前按单活动实例运行；不宣称多活动部署、自动故障转移或已验证的横向扩容。
- 事务、固定版本、权限来源、原操作回执、保存确认和跨服务恢复是核心边界。后续调整以实际行为回归为依据，不因文件或代码较多删除这些机制。

职责划分见[代码组织](../architecture/CODE-ORGANIZATION.md)，运行和配置见[项目README](../../README.md)及[配置说明](../../configs/README.md)。

## 当前功能状态

协作管理支持默认收起的成员选择、服务端搜索、邀请和申请状态筛选、分页及管理归档。013迁移追加归档事实；删除管理记录不会删除原审批事实或撤销已取得的授权。章节菜单接入原固定预览及确认流程。

长列表采用上一页、当前页、下一页，翻页重新读取并替换当前显示项。通知和主评论每页10项，知识库卡片12项，其余管理及版本列表通常20项。组织本人资格独立于成员分页返回；搜索和评论上下文进入服务端筛选与游标绑定。切换身份或范围后，旧页及迟到响应不得重新进入界面。

审核和发布使用固定正文与原操作编号。响应丢失后保留原输入进行恢复；不能通过换号重试、延长期限或忽略错误制造成功。

详细教学证据见[教学验证记录](../tutorial/continuous/09-teaching-verification.md)。机器复原、解释覆盖和源码一致不等于零基础学习者已经亲自完成；自己的工程仍需实际联调。现成产品、教师工具和历史验证不能替代学习成果。
