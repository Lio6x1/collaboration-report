## 实现边界

段落属性通过独立的 `paragraph-formatting.extension.json` 受限追加。原冻结正文 schema、原五个字节样本、HTTP/RPC 和 `BASELINE.json` 均保持原字节；Node 生成器和 Go 校验器读取同一扩展。PM 的默认左对齐、无缩进不回写旧正文，所以单纯打开或刷新不会改变旧正文哈希。

个人文档姓名由 Account 在原身份重验事务中返回，经 Doc 真实管理准入和候选关系交付。内部入口只允许 Doc 服务证书，不增加公开账号目录，不返回邮箱；原身份关闭、权限撤销和分页边界继续有效。

Word 保存原生可编辑的段落对齐与两字符缩进；PDF 使用对应 CSS 排版。Markdown 缺少这些原生语法，因此保留为受控 HTML/CSS；阅读器禁用 HTML/CSS 时无法保证这些格式的展示。
