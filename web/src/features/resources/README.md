# 资源图片前端边界

正文只保存资源编号。图片视图在当前文档的 MAIN 清单、BRANCH 草稿、REVIEW 轮次或 PUBLIC 正式版上下文中请求受控下载地址；不会跨上下文重试或把下载地址写入正文。

编辑器收到原保存协议的 SAVED，且本地队列完成回执核验后，只通知失败或尚未就绪的图片重试。MAIN 重试重新取得保存后的清单，同批请求合并；成功图片不重复下载。视图卸载清理监听器，会话变化禁止继续使用原视图。

## 原冲突输入图片

ConflictInputs三份正文使用原REVIEW轮次。服务端除轮次自身正文/基线外，还会验证同轮次尚有效的原冲突：先定位已物化的VERSION引用，再核对原attempt、摘要、固定输入及真实版本。不会把当前MAIN清单当作历史输入，也不会根据可写索引记录直接放行。

`tests/resources/conflict-content.test.mjs`已通过真实上传、冲突计算、原输入物化和二进制读取；原MAIN独有图片在当前MAIN删图后仍可读，无权成员拒绝，原冲突收据过期后拒绝。前端类型检查与构建通过；未把接口验收表述成新增历史冲突页面的完整浏览器验收。
